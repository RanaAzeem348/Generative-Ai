API Key
A secret key used to authenticate and access the OpenAI API.
Models
AI systems that process prompts and generate responses.
Tokens
Small text units used by language models to process and generate text.
Input / Output
Input is the user prompt; output is the model’s response.
Temperature
Controls creativity. Lower values produce more predictable responses, while higher values produce more creative responses.
Max Tokens
Defines the maximum length of the generated response.


# Generative-AI-Day1

## What is Generative AI?

Generative AI is a type of AI that creates new content such as text, images, audio, and code.

## Difference Between AI, ML, DL and Generative AI

- AI: Intelligent systems
- ML: Learning from data
- DL: Neural networks
- Generative AI: Creates new content

## What are LLMs?

Large Language Models are AI models trained on massive amounts of text data.

## OpenAI API Concepts

### API Key
Used for authentication.

### Models
AI systems that generate responses.

### Tokens
Small text units processed by models.

### Temperature
Controls creativity.

### Max Tokens
Controls response length.
